Source: `self-corrective-rag` (TARA), read from `agentic_rag/`, `experiments/`,
`scripts/` and `configs/` at `github.com/netzkontrast/self-corrective-rag`.

`agentic_rag/` at the repo root. Python `>=3.11`, `uv sync`.

## Tools

`create_tools(retriever, indexer, evaluator, enabled_tools=None) -> list[Callable]`;
`None` enables all seven. Each tool is a closure returning a JSON string.

```python
search_passages(query: str, top_k: int = 10)
decompose_query(question: str)                       # own LLM call, preprocess_model
evaluate_passages(question: str, passage_ids_json: str, retry_count: int = 0)   # own LLM call
get_passage_detail(passage_id: str, include_adjacent: bool = False)
list_document_sections(keyword: str = "")
get_terminology(user_term: str)
calculate(expression: str)                           # restricted eval, math builtins
```

## Agent construction

`AgenticRAGPipeline._run_react_refinement` builds
`dspy.ReAct(sig_cls, tools=tools, max_iters=...)`. `max_iters` comes from
`settings.agent.max_iterations` (10) and is narrowed by
`effective_max_iters() = max(1, (llm_call_budget - 3) // 2)` when a budget is
set.

The signature is generated by
`make_agent_signature(enable_4d=..., has_evaluate=...)`. Inputs: `question`,
`initial_query`, `initial_keywords`, `quality_threshold`, `max_passages`.
Outputs: `final_passages: list[str]`, `final_action: str`.

If the agent never calls evaluation, `_run_mandatory_evaluate` forces one.

`AgenticRAGPipeline(retriever, indexer)` is **not** a `dspy.Module`. It is a
plain class (subclassing `SelfCorrectiveMixin` → `BasePipeline`) holding DSPy
modules. Call `.run(question)` or `.run_timed(question)` → `PipelineResult`.

## Evaluation signature

`EvaluationSignature` inputs: `question`, `passages`, `retry_count`,
`max_retry`. Outputs: `relevance_score` (0–30), `coverage_score` (0–25),
`specificity_score` (0–25), `sufficiency_score` (0–20), `total_score` (0–100),
`action` (`output` | `refine` | `route_to_agent`), `keywords_to_add`,
`keywords_to_remove`, `suggested_query`, `reasoning`.

`Evaluation1DSignature` is the control, selected by
`experiment.enable_4d_evaluation: false`.

The LLM emits `total_score` itself. `pipeline/loop.py` guards it: if
`total == 0` and the four dimensions sum above zero, the sum is substituted.
Threshold: `max(quality_threshold - retry * 5, 20)`, defaults
`quality_threshold: 40`, `max_retry_count: 3` in `configs/base.yaml`.

## Pipelines

`PIPELINE_REGISTRY` in `agentic_rag/config/loader.py`:

| Key | Class | Notes |
|---|---|---|
| `naive` | `NaiveRAGPipeline` | retrieve → generate |
| `crag` | `CRAGReplicaPipeline` | Yan et al. 2024 replica, LLM evaluator in place of the fine-tuned T5 |
| `loop` | `LoopRAGPipeline` | fixed-iteration refinement, the main ablation baseline |
| `ircot` | `IRCoTPipeline` | Trivedi et al. 2023, `max_steps: 8`, `per_step_k: 8`, deviations recorded in the manifest |
| `agentic` | `AgenticRAGPipeline` | TARA |

Selection comes from each variant's `pipeline:` key in the experiment config,
read by `load_experiment_config` → `VariantConfig.import_pipeline_class()`.
`load_config` deep-merges `configs/base.yaml` under the chosen file, then
`apply_settings` mutates the global `settings` singleton in place.

With `experiment.enable_dspy: false`, the DSPy modules are swapped for
`ManualPreprocessor` / `ManualEvaluator` / `ManualGenerator` (raw litellm
prompts) — that is the manual-prompt arm of the ablation.

## Datasets and index

`scripts/prepare_datasets.py --dataset {hotpotqa|2wikimultihopqa|musique|financebench|all} --sample N`
pulls from HuggingFace: `hotpot_qa` (config `distractor`, validation),
`framolfese/2WikiMultihopQA` (validation), `bdsaglam/musique` (validation),
`PatronusAI/financebench` (train, CC-BY-NC-4.0, academic use). Corpora are
self-contained; no external Wikipedia dump is needed for these four.

`scripts/build_index.py --dataset all` builds FAISS (`IndexFlatIP`,
L2-normalized) plus BM25, `section_index` and `term_index` per dataset. The
extra `wikipedia` target needs a manual DPR `psgs_w100.tsv.gz` download of
roughly 21 million passages and supports `--skip-faiss` / `--skip-bm25`.

`experiments/common.py` loads the index and fails if step two was skipped.

## Optimization

```python
optimize_bootstrap(module, trainset, metric_fn=None, max_demos=4, max_rounds=1)
optimize_mipro(...)      # auto="light" only; num_candidates/max_demos are accepted but not passed through
```

Invoked from `experiments/run.py:_apply_optimization` when a variant declares
`optimization:` (only `configs/experiment/rq5.yaml`). Metric is
`token_f1(prediction.answer, example.answer)`. `_find_dspy_module(pipeline)`
selects the `generator` attribute, so only `ChainOfThought(QnAGenerateSignature)`
is compiled. Trainset is cached at `data/optimization/{dataset}_trainset.json`
and needs at least three examples.

## Models and keys

Defaults in `settings.py`: `gpt-4o-mini` for preprocess and evaluate, `gpt-4o`
for generate and agent, `text-embedding-3-small` for embeddings. The published
runs override all four to `gemini/gemini-3.1-flash-lite-preview` with local
`all-MiniLM-L6-v2` embeddings (no key). An open-weight path uses
`ollama_cloud/gpt-oss:120b`. At least one of `OPENAI_API_KEY` or
`GEMINI_API_KEY` is required.

No GPU is needed anywhere (`faiss-cpu`, local MiniLM), though embedding the
21M-passage Wikipedia corpus on CPU is impractical.

## Reproduction controls

| Setting | Why |
|---|---|
| `DISABLE_LLM_CACHE=true` | mandatory whenever latency is reported |
| `LLM_EXPECTED_RESPONSE_MODELS` | aborts if the provider serves a different snapshot |
| `RETRIEVAL_MAX_PASSAGES_ALL_PIPELINES=true` | equalizes passage budgets across pipelines; **off by default** |
| `scripts/verify_campaign.py` | gates a result directory, exits 1 on FAIL |

Raw result JSONL are not committed — only `data/results/RESULTS_SUMMARY.md` —
so the README's table cannot be re-derived without a full paid run.
